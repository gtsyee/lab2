# Лабораторная работа 2: Поиск номеров телефона (Слоистая архитектура)

Чвала Юлия, ИДБ-25-14

## О проекте
Программа осуществляет поиск и нормализацию телефонных номеров с использованием регулярных выражений, с соблюдением принципов SOLID.

## Слоистая архитектура
1. **`data_layer.py`**: Сущность `PhoneNumber`.
2. **`repository_layer.py`**: Абстрактный интерфейс `Repository` и его реализация `MemoryRepository` для хранения найденных номеров в оперативной памяти (CRUD операции).
3. **`service_layer.py`**: Класс `PhoneService` — инкапсулирует бизнес-логику (регулярные выражения, нормализация). Работает с абстракцией репозитория, ничего не зная о деталях реализации хранения (Dependency Inversion).
4. **`main.py`**: Консольный интерфейс. Перехватывает ошибки валидации (`ValueError`) и предоставляет интерактивное меню.
